# ShardIris

ShardIris enables real-time data processing and auto-scaling in a scalable, distributed system architecture for efficient data management.

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/ShardIris.git`
2. `cd ShardIris`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
